🕹️ Arcade-100: The Master Blueprint

A 100-Game Open Source Retro Collection

Welcome to Arcade-100, an ambitious open-source initiative to build 100 retro-inspired browser games entirely in vanilla HTML5, CSS3, and JavaScript.

This project is a rigorous exercise in systems engineering, game logic, and architectural consistency. No frameworks. No engines. Just pure code.
